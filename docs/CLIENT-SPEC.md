# אפיון צד הלקוח (React)

המסמך כולל רק את מה שצריך כדי לבנות את האתר ב־React: מי המשתמשות, אילו מסכים יש, מה כל מסך מציג ומה אפשר לעשות בו, וכללים שחשוב להציג נכון. את פרטי הבקשות לשרת אפשר למצוא ב־`FRONTEND-API-GUIDE.md`.

---

## 1. על המערכת

מערכת לניהול בית ספר: מורות מנהלות מבחנים, ציונים ונוכחות בכיתות שהן מלמדות, תלמידות רואות את הציונים והנוכחות שלהן, ומנהלת מנהלת את בית הספר.

**משתמשות:**

| תפקיד | מה עושה באתר |
| --- | --- |
| מנהלת | מנהלת כיתות, מורות, תלמידות ושיבוצים. יכולה לעשות כל מה שמורה עושה, בכל הכיתות. שולחת הודעות. |
| מורה | רואה רק את הכיתות והמקצועות שלה. מנהלת תקופות ציון, מבחנים, ציונים, נוכחות ומערכת שעות. |
| תלמידה | רואה רק את עצמה: ציונים, נוכחות ומערכת השעות של הכיתה. |

- אין הרשמה. החשבונות נפתחים על ידי המנהלת. במסך הכניסה יש רק כניסה.
- אחיות יכולות להיכנס עם אותו מייל (של ההורים), כל אחת עם סיסמה משלה.
- שיבוץ = מורה + כיתה + מקצוע (למשל: מרים כהן, חומש, ד'1). רוב המסכים של המורה הם "בתוך שיבוץ".

## 2. סדר בנייה מומלץ

**שלב 1: ליבה (עומדת בכל דרישות הפרויקט)**
1. כניסה + שמירת המשתמשת המחוברת + יציאה + הגנה על דפים לפי תפקיד.
2. מורה: הכיתות שלי.
3. מורה: רשימת מבחנים של שיבוץ (סינון לפי תקופה, מיון לפי תאריך, חיפוש).
4. מורה: טופס הוספה ועריכה של מבחן.
5. מורה: הזנת ציונים למבחן.
6. תלמידה: הציונים שלי (סינון לפי מקצוע ותקופה).

**שלב 2: העלאה לענן** של הגרסה שעובדת.

**שלב 3: תוספות לפי הזמן שנשאר** (מהחשוב לפחות חשוב):
ציונים סופיים, תקופות ציון, נוכחות, הנוכחות שלי, מערכת שעות, מסכי המנהלת, הודעות וימי הולדת, ייצוא והדפסה, ייבוא מאקסל, שינוי סיסמה.

בשרת כבר קיים הכול, כך שכל תוספת היא רק עבודה ב־React.

## 4. מסכים

### מסכים משותפים

**כניסה**
- מוצג: שדות מייל וסיסמה, כפתור "כניסה", ובאנר: "מנהלת? רוצה לצרף את בית הספר שלך? צרי קשר" עם קישור מייל (`mailto:`).
- כללים: שני השדות חובה, המייל בפורמט תקין.
- שגיאה: "מייל או סיסמה שגויים".
- בזמן השליחה: הכפתור מושבת ומוצג "מתחבר...".

**סרגל עליון** (בכל הדפים אחרי כניסה)
- שם המשתמשת, שם בית הספר, תפריט לפי התפקיד, כפתור יציאה.
- רשות: אייקון הודעות עם מספר ההודעות שלא נקראו.

**הודעות קופצות אחרי כניסה (רשות)**
- הודעות שלא נקראו וברכות יום הולדת של היום.
- כפתור "סמני כנקראה" וכפתור סגירה.

**תיבת הודעות (רשות)**
- רשימת ההודעות מהחדשה לישנה: כותרת, תוכן, מאת, תאריך, האם נקראה.
- סינון: הכול / לא נקראו / נקראו. פעולות: סימון כנקראה, סימון הכול כנקרא, מחיקה (רק מהתיבה שלי).

**שינוי סיסמה (רשות)**: סיסמה נוכחית, סיסמה חדשה (לפחות 6 תווים), אימות סיסמה חדשה.

### מורה

**הכיתות שלי**
- כרטיס לכל שיבוץ: שם המקצוע, שם הכיתה, מספר תלמידות.
- לחיצה על כרטיס פותחת את מבחני השיבוץ. מתוך השיבוץ יש ניווט ל: מבחנים, ציונים סופיים, תקופות, נוכחות.

**מבחנים של שיבוץ**
- טבלה: כותרת, תאריך, תקופה, משקל, מספר ציונים שהוזנו, ממוצע.
- סינון: לפי תקופה (רשימה נפתחת), טווח תאריכים, חיפוש לפי כותרת. מיון: תאריך / כותרת / משקל.
- לכל תקופה מוצג "הוגדרו X% מתוך 100%".
- פעולות: מבחן חדש, עריכה, מחיקה (עם אישור), מעבר להזנת ציונים.

**טופס מבחן (הוספה ועריכה, אותו טופס)**

| שדה | סוג | חובה | כלל |
| --- | --- | --- | --- |
| כותרת | טקסט | כן | 2-80 תווים |
| תאריך | תאריך | כן | |
| תקופה | בחירה מרשימה | כן | תקופות השיבוץ |
| משקל (%) | מספר | כן | מספר שלם 1-100, ולא יותר ממה שנשאר בתקופה |
| תיאור | טקסט ארוך | לא | עד 500 תווים |

- כדאי להציג ליד המשקל: "נשאר עוד X% בתקופה זו".
- אם השרת מחזיר שגיאת משקל, מציגים את ההודעה שלו.

**הזנת ציונים**
- כותרת המבחן, התאריך והמשקל.
- טבלה: שם התלמידה, שדה ציון, שדה הערכה מילולית (רשות).
- ציון: 0-100, אפשר עשרוני עם עד שתי ספרות (98.5, 99.25). שדה ריק = אין ציון.
- כפתור "שמירה" ששומר את כל הטבלה בבת אחת, והודעה "נשמר".

**ציונים סופיים**
- טבלה: שם התלמידה, ציון בכל מבחן, ציון כל תקופה, ציון שנתי.
- תקופה שלא הושלמה מוצגת כ"לא הושלמה". אם אי אפשר לחשב ציון שנתי, מוצגת ההודעה מהשרת, למשל "במחצית ב' עדיין לא הוגדרו מבחנים".
- מיון: לפי שם משפחה, שם פרטי או ציון שנתי.
- רשות: כפתור "ייצוא לאקסל" וכפתור "הדפסה".

**תקופות ציון**
- רשימה: שם, משקל, כמה אחוז מבחנים הוגדרו, האם הושלמה. בראש: "סך התקופות: X%".
- פעולות: הוספה (שם + משקל), שינוי שם ומשקל, מחיקה (רק תקופה בלי מבחנים).
- ברירת המחדל לכל שיבוץ: מחצית א' 50%, מחצית ב' 50%. אפשר לשנות לשמות אחרים (סמסטר א'/ב'/ג') או למשקלים אחרים, למשל 100% ו־0% לקורס של מחצית אחת.

**נוכחות: סימון לשיעור**
- בחירת תאריך (לא עתידי) ושעה (1-10).
- טבלה של כל תלמידות הכיתה. בכל שורה תא סימון: לחיצה מחליפה בין ריק (נוכחת) ← `+` (איחור) ← `-` (חיסור) ← `ש` (שחרור) ← ריק.
- לכל חריגה אפשר לסמן "מאושר" ולכתוב סיבה.
- כפתור "שמירה". גם בלי חריגות אפשר לשמור (פירושו: כולן נכחו).

**נוכחות: היסטוריה**
- טבלה: תאריך, שעה, תלמידה, סימן, מאושר, סיבה.
- סינון: טווח תאריכים, סטטוס, מאושר/לא, חיפוש לפי שם פרטי או משפחה.
- פעולות: סימון מאושר + סיבה, שינוי סטטוס, מחיקה (התלמידה תיחשב נוכחת).

**המערכת שלי**
- טבלה שבועית: ימים א'-ו' בעמודות, שעות בשורות. בכל תא: מקצוע + כיתה.
- פעולות: הוספת שיעור (שיבוץ, יום, שעה, חדר), שינוי, מחיקה. אם יש התנגשות, השרת מחזיר הודעה מתאימה.

### תלמידה

**הציונים שלי**
- לכל מקצוע: שם המורה, ולכל תקופה: רשימת המבחנים (כותרת, תאריך, משקל, ציון, הערכה), ציון התקופה, וציון שנתי.
- תקופה שלא הושלמה: "טרם הושלמה". מבחן בלי ציון: "-".
- סינון: לפי מקצוע ולפי תקופה.

**הנוכחות שלי**
- סיכום בראש הדף: מספר איחורים, חיסורים ושחרורים, ואחוז נוכחות. מתחת: סיכום לפי מקצוע.
- טבלה: תאריך, שעה, מקצוע, סימן, מאושר, סיבה.
- סינון: סטטוס, מקצוע, טווח תאריכים.

**מערכת השעות**
- אותה טבלה שבועית כמו של המורה, לצפייה בלבד. בכל תא: מקצוע + שם המורה.
- אפשר להשתמש באותה קומפוננטה של המורה ולהעביר לה נתונים אחרים (Props).

### מנהלת

**כיתות**: טבלה (שם, שכבה, מספר תלמידות), סינון לפי שכבה. הוספה (שכבה + מספר בשכבה; השם, למשל ד'2, נוצר לבד), עריכה, מחיקה (רק כיתה ריקה).

**מורות ותלמידות**
- טבלה עם עימוד: שם פרטי, שם משפחה, תפקיד, כיתה, טלפון, מייל, פעילה.
- חיפוש לפי שם פרטי, שם משפחה או חופשי. סינון: תפקיד, כיתה, פעילות/מושבתות. מיון: שם פרטי / שם משפחה.
- פעולות: הוספה, עריכה, העברת כיתה, השבתה (במקום מחיקה), איפוס סיסמה (מציגים את הסיסמה החדשה פעם אחת).

**טופס משתמשת**

| שדה | חובה | הערה |
| --- | --- | --- |
| תפקיד | כן | מורה / תלמידה (רק ביצירה) |
| שם פרטי, שם משפחה | כן | 2-40 תווים |
| מייל | כן | אחיות יכולות לקבל אותו מייל |
| תעודת זהות | לתלמידה | 9 ספרות, נבדקת ספרת ביקורת |
| סיסמה | לא | אם ריק, נוצרת סיסמה אוטומטית ומוצגת פעם אחת |
| טלפון | לא | |
| כתובת | לא | |
| תאריך לידה | לתלמידה | לא בעתיד. מוצג גם התאריך העברי |
| כיתה | לתלמידה | בחירה מרשימה |

**שיבוצים**: טבלה (כיתה, מקצוע, מורה), סינון לפי כיתה/מורה/מקצוע. הוספה (כיתה + מקצוע + מורה), החלפת מורה, מחיקה.

**מקצועות (רשות)**: רשימה, הוספה, שינוי שם, מחיקה.

**שליחת הודעה (רשות)**: כותרת, תוכן, למי (כל המורות והתלמידות / כל המורות / כל התלמידות / כיתה מסוימת).

**ייבוא תלמידות מאקסל (רשות)**: כפתור "הורדת קובץ לדוגמה", בחירת קובץ, העלאה. בהצלחה: כמה נוספו + טבלת סיסמאות + כפתור "הורדת קובץ סיסמאות". בשגיאה: רשימת שגיאות לפי שורה (לא נשמר כלום).

**ייצוא (רשות)**: רשימת תלמידות (כל בית הספר או כיתה), רשימת מורות, ציונים של שיבוץ.

## 5. כללים שחשוב להציג נכון

**ציונים**
- ציון: 0-100, עד שתי ספרות אחרי הנקודה.
- ציון תקופה מחושב רק כשמשקלי המבחנים בתקופה = 100%. ציון שנתי מחושב רק כשמשקלי התקופות = 100% וכל תקופה עם משקל הושלמה. החישוב נעשה בשרת, ובאתר רק מציגים.
- מבחן בלי ציון נחשב 0 בחישוב.
- ציונים מחושבים מעוגלים לספרה אחת.

**נוכחות**

| סימן | משמעות |
| --- | --- |
| (ריק) | נוכחת |
| + | איחור |
| - | חיסור |
| ש | שחרור |

- רק חריגות נשמרות. חריגה יכולה להיות "מאושרת" עם סיבה.
- אין ציון נוכחות. מוצג אחוז נוכחות, וחיסור מאושר לא מוריד ממנו.

**ימי הולדת (רשות)**: לפי התאריך העברי. מורה רואה ברכה לתלמידות שהיא מלמדת, ותלמידה רואה ברכה אישית ביום ההולדת שלה. נוסח הברכה מגיע מוכן מהשרת.

**הודעות (רשות)**: רק המנהלת שולחת. מחיקה מוחקת רק מהתיבה של מי שמחקה.

**תאריכים**: תאריך לידה מוצג גם כלועזי וגם כעברי (שניהם מגיעים מהשרת).

**מצבים בכל מסך**: בזמן טעינה מציגים "טוען...", בשגיאה מציגים את ההודעה שהשרת מחזיר (בעברית), וכשהרשימה ריקה מציגים הודעה מתאימה.
